# برنامج المحاسبة للمطابع

الإصدار المحدث: واجهة حديثة + طلبات عمل مبسطة + تقارير + نسخة احتياطية.

## طلبات العمل
الحقول الظاهرة عند الإضافة فقط:
1. اسم الزبون
2. رقم الهاتف
3. القياس
4. الكمية
5. عدد النسخ (1 إلى 8 نسخ مكربن)
6. المبلغ الكلي
7. العربون
8. نوع الطباعة

المبلغ المتبقي يحسب تلقائيًا. رقم الطلب يتم توليده من قاعدة البيانات ولا يرسل من الواجهة.
عدد النسخ يحفظ داخليًا داخل حقل الملاحظات بصيغة JSON لتجنب الحاجة إلى تعديل قاعدة البيانات الحالية.

## إضافات الإصدار
- البحث عن الزبون بالاسم أو الهاتف مع ملخص سجل الزبون.
- تغيير حالة الطلب من الجدول.
- طباعة إيصال طلب العمل.
- رابط اتصال مباشر برقم الهاتف على الأجهزة الداعمة.
- تقارير حسب فترة مع طباعة A4.
- نسخة احتياطية JSON من بيانات البرنامج من صفحة الإعدادات.
- إزالة قسم الدفعات من واجهة البرنامج مع إبقاء جداول قاعدة البيانات التاريخية دون حذف.
- إزالة خانة البيان من الوارد والمصروف.
